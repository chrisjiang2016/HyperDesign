### 1.2 本轮优化重点（v1.1）

本轮原型升级，重点不是“补更多页面”，而是把关键页面从“高保真页面”进一步提升到“更像正式产品”的演示状态：

1. **新增统一演示入口页 `demo.html`**
   - 方便直接开始演示
   - 提供页面导航与推荐演示路径
   - 更适合产品评审和研发评审现场展示

2. **首页升级为工作台式首页**
   - 增加顶部 Hero 区
   - 增加数据概览卡片
   - 增加最近活动面板
   - 团队卡片视觉与信息层级更完整

3. **项目详情页升级为项目工作台**
   - 增加项目摘要区和右侧说明面板
   - 强化文件资产列表、筛选、搜索
   - 更接近真实 B 端后台产品形态

4. **原型预览页升级为专业评审界面**
   - 更明确的页面树 + 画布 + 评论面板三栏布局
   - 标注模式增加尺寸与属性展示氛围
   - 画布区不再只是占位，而是模拟真实首页原型内容

### 1.3 设计风格

> ⚠️ **视觉基准以各 HTML 页面内联 CSS 为准**。以下为 2026-07-15 设计对齐后的冻结规范。

- **配色方案**：蓝系 SaaS 主题（主色 `#2563eb`，hover `#1d4ed8`，浅底 `#f8fafc`）
- **已废弃**：旧版紫渐变主色（`#667eea → #764ba2`）不再作为产品主视觉
- **字体**：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif`
- **圆角**：`8px / 10px / 12px / 16px`
- **阴影**：轻分层阴影（`--shadow-sm` / `--shadow-md`）
- **动画**：`0.18s ease` 为主，克制过渡
- **信息架构**：Topbar + 左侧导航树 + 主内容 + 右侧活动/协作栏 的 B 端工作台

## 二、页面详细说明

### 2.1 登录页（login.html）

#### 功能说明
- 用户名 + 密码登录
- 记住我选项
- 忘记密码链接
- 注册引导

#### 交互逻辑
1. 输入用户名和密码
2. 点击【登录】按钮
3. 验证通过后跳转到 `index.html`（我的团队）
4. 验证失败显示错误提示

#### 表单验证
- 用户名：字母或数字，5位以上
- 密码：字母或数字，6位以上

#### 页面跳转
- 忘记密码 → `forgot-password.html`
- 注册 → `register.html`
- 登录成功 → `index.html`

### 2.2 注册页（register.html）

#### 功能说明
- 用户名输入（需确认）
- 密码输入
- 实时表单验证
- 服务条款链接

#### 交互逻辑
1. 输入用户名（需输入两遍确认）
2. 输入密码
3. 失焦时实时验证
4. 点击【注册】提交
5. 注册成功后跳转登录页

#### 表单验证
- 用户名：仅支持英文字母或数字，长度 5 位以上
- 确认用户名：必须与第一次输入一致
- 密码：仅支持英文字母或数字，长度 6 位以上

#### 验证提示
- 实时验证：失焦时触发
- 错误状态：红色边框 + 错误文字
- 成功状态：移除错误标记

#### 页面跳转
- 已有账号 → `login.html`
- 注册成功 → `login.html`（带成功提示）

### 2.3 忘记密码页（forgot-password.html）

#### 功能说明
- 输入用户名重置密码
- 系统生成临时密码
- 模态框显示新密码

#### 交互逻辑
1. 输入用户名
2. 点击【重置密码】
3. 系统验证用户名是否存在
4. 生成 8 位随机密码
5. 模态框弹出显示新密码
6. 点击【前往登录】跳转登录页

#### 密码生成规则
- 长度：8 位
- 字符集：a-z, A-Z, 0-9
- 随机生成

#### 错误处理
- 用户名不存在：显示红色提示 3 秒后自动消失

#### 页面跳转
- 返回登录 → `login.html`
- 重置成功后前往登录 → `login.html`

## 三、全局交互规范

### 3.1 按钮交互

| 按钮类型 | 样式特征 | 悬停效果 | 点击效果 |
|---------|---------|---------|---------|
| 主按钮 | 实心蓝 `#2563eb` | hover `#1d4ed8` | 无强制位移 |
| 次按钮 | 白底 + 浅边框 | 背景 `#f9fafb` | 无 |
| 危险按钮 | 红色背景 / 危险区 | hover 强化 | 退出等场景 |
| 图标按钮 | 白底 + 浅边框 | 背景变浅灰 | 通知、操作 |

### 3.2 表单验证

- **验证时机**：失焦（blur）时触发
- **错误状态**：红色边框 + 错误文字
- **成功状态**：移除错误标记
- **提交验证**：统一在表单提交时再次验证

### 3.3 模态框

- **背景遮罩**：半透明黑色（rgba(0,0,0,0.5)）
- **弹出动画**：向上滑入 + 淡入
- **关闭方式**：
  - 点击关闭按钮
  - 点击背景遮罩
  - 按 ESC 键（部分页面未实现）

### 3.4 导航与面包屑

- **Logo**：始终可点击返回首页
- **面包屑**：显示当前路径，可点击返回上级

## 五、技术实现说明

### 5.1 技术栈

- **纯 HTML + CSS + JavaScript**：无框架依赖
- **内联样式**：所有 CSS 写在 `<style>` 标签内
- **内联脚本**：所有 JS 写在 `<script>` 标签内
- **自包含**：每个页面独立运行，无外部依赖

### 5.2 响应式设计

- **视口适配**：使用 `viewport` meta 标签
- **网格布局**：使用 CSS Grid 自适应
- **最小宽度**：部分页面设置最小宽度避免过窄
- **移动端优化**：评论面板、预览区支持触摸滚动

### 5.3 浏览器兼容性

- **现代浏览器**：Chrome、Firefox、Safari、Edge
- **CSS 特性**：Flexbox、Grid、CSS 变量
- **JS 特性**：ES6 语法（箭头函数、模板字符串）

### 5.4 数据模拟

- **所有交互均为前端模拟**
- 实际使用时需要对接后端 API
- 建议参考 `HyperDesign_API接口设计_v1.0.md`

## 六、使用说明

### 6.1 本地预览

1. 解压或克隆项目到本地
2. 进入 `prototype/` 目录
3. 用浏览器打开 `login.html` 开始体验
4. 或使用本地服务器（如 Live Server）运行

### 6.2 推荐预览顺序

1. **登录页** → 体验登录流程
2. **我的团队** → 查看团队列表
3. **团队详情** → 切换项目/成员标签
4. **项目详情** → 查看文件树
5. **原型预览** → 体验标注与评论
6. **个人设置** → 修改密码流程

### 6.3 注意事项

- 所有表单提交、登录、注册均为前端模拟
- 实际数据不会保存
- 页面刷新后状态重置
- 建议使用 Chrome 浏览器预览

## 七、后续开发对接

### 7.1 需要对接的后端接口

参考 `HyperDesign_API接口设计_v1.0.md`，关键接口包括：

- `POST /api/auth/login` - 登录
- `POST /api/auth/register` - 注册
- `POST /api/auth/reset-password` - 重置密码
- `GET /api/teams` - 获取团队列表
- `POST /api/teams` - 创建团队
- `GET /api/projects` - 获取项目列表
- `POST /api/files/upload` - 上传文件
- `GET /api/files/:id/preview` - 预览文件
- `POST /api/comments` - 添加评论

### 7.2 需要替换的占位内容

- **用户头像**：目前使用首字母，需替换为真实头像
- **团队图标**：目前使用 Emoji，可替换为上传图标
- **iframe 预览**：需加载实际 HTML 文件
- **页面列表**：需动态加载 ZIP 解析后的页面列表
- **评论标记点**：需根据实际点击位置保存坐标

### 7.3 需要增强的功能

## 九、设计规范总结

### 9.1 间距系统

- 4px - 最小间距单位
- 8px / 10px - 组件内间距
- 12px / 14px - 小型间距
- 16px / 18px - 标准间距
- 20px / 22px / 24px - 中大间距
- 28px / 32px - 区块间距
- 36px / 40px - 页面边距

### 9.2 字号系统

- 12px - 辅助文字 / meta
- 13px - 面包屑、次级说明
- 14px - 正文文字
- 15px - 正文文字（加强）
- 16px - 小标题 / Viewer 标题
- 18px - Brand / 中标题
- 24px - 页面标题
- 28px - Hero 标题
- 30px - Summary 数值

### 9.3 圆角系统

- 8px - 输入框、小控件
- 10px - 按钮、搜索框、导航项
- 12px - 卡片内块、切换器
- 16px - 主卡片、面板、模态框
- 999px - 头像 / pill

### 9.4 阴影系统

- 轻阴影：`0 1px 2px rgba(16,24,40,0.04), 0 1px 3px rgba(16,24,40,0.08)`
- 中阴影：`0 4px 12px rgba(16,24,40,0.08), 0 8px 32px rgba(16,24,40,0.12)`
- Viewer 阴影：`0 8px 24px rgba(15,23,42,0.08)`

### 9.5 布局尺寸

- Topbar：`64px`
- Sidebar：业务页 `232px`，Viewer `240px`
- Rightbar：首页 `304px`，团队/项目/设置 `300px`，Viewer `340px`
- 响应式：`<1180px` 隐藏右栏；`<860px` 隐藏侧栏与部分 Topbar 元素
