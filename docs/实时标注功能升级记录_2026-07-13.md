## 1. 升级内容

将原本"写死的标注占位 UI"升级为 **真正可交互的实时标注引擎（Inspect Engine）**。

### 1.1 升级前 vs 升级后

| 维度 | 升级前 | 升级后 |
|------|--------|--------|
| 高亮 | 静态写死一个方框 | Hover 任意元素实时跟随 |
| 距离显示 | 1 条写死的 40px | 4 边距离 + 最近兄弟距离，全部 2 位小数 |
| 交互 | 仅视觉占位 | Hover / 点击锁定 / Tab 跳转 / ESC 退出 |
| 元素信息 | 静态文字 | 实时计算 tag、class、宽高、X/Y、字号、圆角 |
| 缩放适配 | 无 | 缩放时自动重新换算坐标 |

### 1.2 4 个核心需求实现

| # | 需求 | 实现方式 |
|---|------|----------|
| 1 | 展示到画布 **4 边距离** | 在元素 4 条边外侧各画 1 条带端点的标尺线 + 1 个标签 |
| 2 | **距最近兄弟元素** | 遍历父级子节点，按方向（上下左右）选距离最近且不重叠的兄弟，画连线 + 标签 |
| 3 | **Hover 触发** + **选中高亮** + **ESC 退出** | mousemove 实时刷新；点击切换 locked 态（蓝→绿）；ESC 调用 toggleInspect 关闭 |
| 4 | **Tab 在元素间跳转** | 构建 tabCycle 列表（排除 overlay 自身元素），Tab/Shift+Tab 顺序跳转 |
| 5 | **2 位小数** | `fmt = n => (Math.round(n*100)/100).toFixed(2)` |

### 1.3 视觉表现

- **元素高亮框**：1.5px 蓝色边框 + 10% 蓝色背景填充 + 4 个角标
- **锁定态**：变绿色（#22c55e），代表"已选中"
- **4 边标尺**：粉红色（#ff5a7a）渐变线，两端带短刻度，中部带 px 标签
- **兄弟距离标尺**：粉红色实线 + 标签（含方向箭头和兄弟元素 tag/class）
- **属性信息卡**：右上角弹出，半透明深色背景，分 4 段：标题/4 边距离/自身信息/最近兄弟
- **顶部提示条**：开启标注时顶部居中显示快捷键提示（Tab / Esc）

### 1.4 兼容性

- ✅ 缩放（60%~200%）时自动重新计算并重绘
- ✅ 缩放时坐标使用 `/scale` 换算回逻辑坐标
- ✅ 与"评论模式"互斥，切换时清理 overlay
- ✅ 窗口 resize 时自动重绘当前选中元素
- ✅ 响应式断点（1220px / 900px）保留

## 2. 关键技术决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 坐标系 | 逻辑坐标（除以 scale） | 缩放时数据稳定，标注值始终是元素"原始尺寸" |
| 兄弟识别 | 同父节点 + 同方向 + 不重叠 | 排除无意义的"跨行"兄弟 |
| 兄弟方向 | top / bottom / left / right 4 方向判别 | 覆盖 Figma Inspect 的核心场景 |
| 标签定位 | 默认右上角，超界翻面到左上 | 避免遮挡元素本身 |
| Tab 列表 | 排除 overlay/banner 自身元素 | 防止 Tab 跳到 UI 而不是原型 |
