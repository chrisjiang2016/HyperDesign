# 开发任务拆分与排期建议：HTML 原型分享平台 v1.0

> 文档版本：v1.0  
> 创建时间：2026-07-10  
> 关联文档：PRD、技术架构与数据库设计、API 接口设计  
> 文档用途：研发排期、任务拆分、里程碑管理、测试验收

---

## 1. 版本目标

V1 需要完成一个可交付的 HTML 原型分享平台，核心链路为：

```text
注册 / 登录
→ 管理员创建团队
→ 创建项目 / 文件夹
→ 上传 ZIP 原型包
→ 解压识别 HTML 页面目录
→ 在线预览
→ 标注查看元素信息
→ 添加评论和回复
→ 生成分享链接
→ 外部用户注册/登录后按分享设定访问
```

## 3. 推荐开发周期

若 2 名前端 + 2 名后端 + 1 名测试：建议 **6-8 周**。

| 阶段 | 周期 | 目标 |
|---|---:|---|
| 第 0 周 | 2-3 天 | 技术验证 Spike |
| 第 1-2 周 | 2 周 | 基础账号、团队、项目、文件夹、权限框架 |
| 第 3-4 周 | 2 周 | ZIP 上传解析、Axure 预览、资源访问 |
| 第 5 周 | 1 周 | 分享链接、评论与回复 |
| 第 6 周 | 1 周 | 标注模式、联调、修复 |
| 第 7-8 周 | 1-2 周 | 系统测试、安全加固、验收上线 |

## 4. 里程碑拆分

## M0：技术验证 Spike

### 目标

优先验证高风险技术点，避免进入开发后返工。

### 任务

| 编号 | 任务 | 负责人 | 验收标准 |
|---|---|---|---|
| M0-1 | 准备 Axure 复杂动态面板 ZIP 样例 | 产品/测试 | 至少 1 个复杂动态面板样例，1 个多层页面树样例 |
| M0-2 | 验证 ZIP 解压与 HTML 扫描 | 后端 | 可识别多层 HTML 页面目录 |
| M0-3 | 验证 Axure 预览资源加载 | 后端/前端 | 页面树、动态面板、图片、JS 可用 |
| M0-4 | 验证 iframe DOM 读取 | 前端 | 可通过同源 iframe 获取元素尺寸和 computedStyle |
| M0-5 | 验证评论坐标相对定位 | 前端 | 页面缩放后评论点位置基本稳定 |

### 出口标准

1. Axure 复杂样例可预览。
2. iframe 标注技术可行。
3. ZIP 解压安全方案明确。
4. 评论坐标方案可行。

## M1：账号与权限基础

### 后端任务

| 编号 | 任务 | 说明 |
|---|---|---|
| BE-1 | 初始化项目结构 | Node/NestJS 或团队选型框架 |
| BE-2 | 数据库初始化 | users、teams、team_members 等基础表 |
| BE-3 | 注册接口 | 用户名规则：字母数字、5 位以上、唯一 |
| BE-4 | 登录 / 登出接口 | Session Cookie |
| BE-5 | 忘记密码接口 | 输入用户名，重置并返回临时密码 |
| BE-6 | 修改密码接口 | 校验原密码、新密码规则 |
| BE-7 | 用户角色接口 | 主管理员、子管理员、员工 |
| BE-8 | 鉴权中间件 | 未登录、无权限统一拦截 |

### 前端任务

| 编号 | 任务 | 说明 |
|---|---|---|
| FE-1 | 登录页 | 用户名、密码、忘记密码、注册入口 |
| FE-2 | 注册页 | 用户名、确认用户名、密码 |
| FE-3 | 忘记密码页 | 输入用户名、弹窗展示临时密码 |
| FE-4 | 个人设置页 | 修改密码 |
| FE-5 | 路由守卫 | 未登录跳转登录 |

### 验收标准

1. 用户可注册、登录、登出。
2. 重复用户名不能注册。
3. 密码可重置。
4. 用户可修改密码。
5. 未登录不能访问业务页面。

## M3：ZIP 上传、解析与预览

### 后端任务

| 编号 | 任务 | 说明 |

| BE-15 | ZIP 类型校验 | 非 ZIP 拒绝 |

| BE-20 | Axure 包兼容 | 保留目录结构和资源路径 |
| BE-21 | 预览资源访问接口 | 统一鉴权返回 HTML/CSS/JS/图片 |

### 前端任务

| 编号 | 任务 | 说明 |
|---|---|---|
| FE-11 | 上传 ZIP 弹窗 | 文件选择、大小提示、上传进度 |
| FE-12 | 解析状态展示 | 解析中、成功、失败 |

## M4：文件权限与分享链接

### 后端任务

| 编号 | 任务 | 说明 |
|---|---|---|
| BE-22 | file_permissions 表与接口 | 查看、评论、编辑、删除 |
| BE-23 | 文件列表权限过滤 | 普通员工只看有权限文件 |
| BE-24 | 资源访问鉴权 | 预览资源必须 can_view |

| BE-26 | 分享链接访问接口 | 判断过期、撤销 |
| BE-27 | 接受分享授权接口 | team_invite / file_only |
| BE-28 | 撤销分享链接接口 | 写入 revoked_at |

### 前端任务

| 编号 | 任务 | 说明 |
|---|---|---|
| FE-16 | 文件权限弹窗 | 设置用户级权限 |
| FE-17 | 分享弹窗 | 分享设定、权限、有效期天数 |

1. 权限不继承。
2. 无 can_view 不能预览。
3. 分享链接可设置有效期天数。
4. 过期链接不可访问。
5. 撤销链接不可访问。
6. team_invite 加入团队，file_only 不加入团队。

## 5. 任务依赖关系

```text

  ↓
团队/成员/项目/文件夹
  ↓
文件上传/解析
  ↓
预览资源访问
  ↓

  ↓

  ↓
评论/回复
  ↓

  ↓
```

说明：

1. 标注模式依赖 iframe 预览资源可同源访问。
2. 评论依赖文件、页面、权限。
3. 分享依赖文件权限。
4. Axure 兼容必须在 M0 和 M3 都持续验证。

## 8. 结论

本项目 V1 的研发重点是：

1. **先验证高风险技术点**：Axure 动态面板、页面树、iframe 标注。
2. **再搭基础业务框架**：账号、团队、项目、文件夹。
3. **再做核心文件能力**：ZIP 上传、解压、页面识别、预览。
4. **最后完善协作能力**：权限、分享、评论回复、标注。

建议不要一开始就进入完整页面开发，先完成 M0 技术验证，否则 Axure 兼容和标注模式可能造成返工。
