## 五、设计规范总结

### 5.1 配色方案

- **主色**：渐变紫（#667eea → #764ba2）
- **背景**：白色 #FFFFFF，浅灰 #F5F7FA
- **文字**：深灰 #1A202C，中灰 #4A5568，浅灰 #718096
- **错误**：红色 #FC8181
- **成功**：绿色 #48BB78

### 5.2 间距系统

- 8px / 12px / 16px / 20px / 24px / 32px / 40px

### 5.3 字号系统

- 12px（辅助）/ 14px（正文）/ 15px（加强）/ 18px（中标题）/ 24px（页面标题）/ 32px（主标题）

### 5.4 圆角系统

- 6px（小按钮）/ 8px（标准按钮）/ 12px（卡片）/ 16px（模态框）/ 50%（圆形）

### 5.5 阴影系统

- 轻：`0 2px 8px rgba(0,0,0,0.06)`
- 标准：`0 4px 12px rgba(0,0,0,0.1)`
- 加强：`0 12px 24px rgba(0,0,0,0.12)`
- 深：`0 20px 60px rgba(0,0,0,0.3)`

## 六、如何使用原型

### 6.1 预览方式

**方式 1：直接打开（最简单）**
1. 进入 `prototype/` 目录
2. 双击 `login.html` 开始预览

**方式 2：Live Server（推荐）**
1. 用 VS Code 打开项目
2. 安装 Live Server 插件
3. 右键 `login.html` → Open with Live Server

### 6.2 推荐预览流程

```
1. login.html（登录）
   ↓ 输入用户名密码，点击登录
2. index.html（我的团队）
   ↓ 点击团队卡片
3. team-detail.html（团队详情）
   ↓ 切换"项目"标签页，点击项目卡片
4. project-detail.html（项目详情）
   ↓ 点击文件项
5. prototype-viewer.html（原型预览）⭐ 核心
   ↓ 点击标注模式、评论模式、页面切换
6. user-settings.html（个人设置）
   ↓ 修改密码
```
